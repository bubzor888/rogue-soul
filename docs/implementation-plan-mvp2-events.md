# Soul Protocol — MVP2 Implementation Plan (Plan 2 of 2: Non-Combat Events)

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended)
> or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`)
> syntax for tracking.

**Goal:** Build the non-combat room layer MVP1 deferred — the `TradeGenerator`, the trade/option actions,
the `NON_COMBAT_EVENT` orchestration, floor generation of Memory Fragment / Wandering Soul / Rest beats,
and the three player-facing screens — so a Pilgrim Floor-3 run produces and resolves every room type the
specs define, first headlessly (AI-driven) and then through the UI.

**Architecture:** Two halves. **Part A — Engine** (phases PE0–PE5): the same headless, TDD, four-layer
engine style as MVP1 — a `TradeGenerator` (`LLD-ARCH-021`) that mints serialisable `TradeOffer`
dictionaries, `ActionInjector` gaining the `ACCEPT_TRADE`/`DECLINE_TRADE`/`ACCEPT_OPTION_1`/
`ACCEPT_OPTION_2` actions, `RunController` orchestrating the `NON_COMBAT_EVENT` phase and generating the
MF/WS/Rest beats, all driven to completion by `AIPlayerAgent` and pinned by the determinism gate.
**Part B — UI** (phases PE6–PE9): the Memory Fragment, Wandering Soul, and Rest screens, built on Plan 1's
presentation foundation (`GameSession`/`ScreenManager`, `ArtPaths`, `DisplayText`, view-model + thin-view
pattern, `bind(run, content)`).

**Tech Stack:** Godot 4.6.x, GDScript, GdUnit4 v6.1.3 (engine TDD), Godot `Control`/`Container` UI
(anchors only), the Plan 1 presentation foundation.

## Scope & sequencing

This is the second of the two MVP2 plans (`SCOPE-002`), split by decision 2026-07-10:

- **Plan 1 — Presentation Layer** (`docs/implementation-plan-mvp2.md`): foundation + room-select, combat +
  omen overlay, loot. **Prerequisite for Part B here** (the screens reuse its `GameSession`,
  `ScreenManager` path registry, `ArtPaths`, `DisplayText`, components, and the view-model/thin-view
  pattern). Part A (engine) does **not** depend on Plan 1 and can proceed in parallel.
- **Plan 2 — this document**: the non-combat events feature end to end.

**Internal boundary:** Part A (PE0–PE5) is independently shippable and testable — on completion
`AIPlayerAgent.run_to_completion()` drives a full Floor-3 run that *includes* Memory Fragment, Wandering
Soul, and Rest rooms, fully deterministic per seed, verified by the determinism gate with **no UI**
(exactly the MVP1 bar, extended to the new room types). Part B (PE6–PE9) then renders those rooms.
Execution may checkpoint at the end of PE5.

### "Elite Gate" is not a screen (resolved)

The Elite Gate (`LLD-FLOOR-BEATS-004`) is **room 5's two-door choice** — one elite-combat door, one
standard-combat door — already generated by `NavigationModel._elite_gate_doors` and rendered by Plan 1's
room-select screen. It is **not** a non-combat trade event and needs no dedicated screen here. What Plan 2
adds around it is the *consequence*: choosing the **elite** door forces a guaranteed **Rest** at room 6
(`LLD-FLOOR-BEATS-006`) — that's engine work in PE4, and the Rest screen in PE6.

## Canonical facts (verified against the code & specs)

**Phase & state (already present — no schema churn for these):**
- `GameState.RunPhase.NON_COMBAT_EVENT` exists.
- `NavigationState` already has `event_type: String` (`""` outside the phase) and
  `event_offers: Array[Dictionary]`, plus `rooms_completed_this_floor: int`,
  `segment_room_counts: Dictionary`, `companion_offered_this_floor: bool`, `doors_ahead: Array[DoorData]`,
  `loot_offers: Array[String]`.
- `DoorData{room_type, encounter_id, room_id}`. `NavigationModel` room-type constants today:
  `ROOM_COMBAT="combat"`, `ROOM_ELITE_COMBAT="elite_combat"`, `ROOM_COMPANION="companion"`.

**Action shapes (`LLD-ARCH-003`, verified):**
```
{ "type": "ACCEPT_TRADE",   "offer_index": N }   # WS + MF Cat A
{ "type": "DECLINE_TRADE" }                        # WS + MF Cat A (walk away)
{ "type": "ACCEPT_OPTION_1" }                      # MF Cat C only
{ "type": "ACCEPT_OPTION_2" }                      # MF Cat C only
```
`event_type` values: `"wandering_soul"`, `"mf_cat_a"`, `"mf_cat_c"`. (`"companion"` and `"rest"` are
handled as beats, not trade events — see PE3.) `DECLINE_TRADE` is legal for `wandering_soul`/`mf_cat_a`
but **not** `mf_cat_c` (must choose an option). After the last WS offer is taken, or on any
decline/option-resolution, RunController transitions to `NAVIGATION`.

**TradeOffer dictionary (`LLD-ARCH-021`, GameState-serialisable):**
```
{ "offer_type": String,      # "item_for_item"|"item_for_hp"|"hp_for_item"|"consumable_for_item"|"loss_only"
  "give_item_id": String,    # ability_id given up; "" if HP cost
  "give_hp": int,            # HP paid; 0 if item cost
  "receive_item_id": String, # ability_id received; "" if HP reward
  "receive_hp": int }        # HP received; 0 if item reward
```

**`TradeGenerator` interface (`LLD-ARCH-021`):** `generate_wandering_soul_offers(gs) -> Array[Dictionary]`
(2–3 offers, ≥1 `hp_for_item`, `HLD-WS-003`), `generate_category_a_offer(gs) -> Dictionary` (one fair
trade), `generate_category_c_offers(gs) -> Array[Dictionary]` (exactly 2: bad deal + loss-only),
`is_fair_trade(a, b) -> bool` (`|a-b| ≤ 0.20×max(a,b)`), `hp_for_score(score, scale) -> int`.

**Fairness/threshold formulas:** fair = `|a-b| ≤ 0.20×max(a,b)` (`LLD-IR-010`). Cat C Option-1 cost `C`
vs reward `R`: `C ≥ R × 1.70` (`LLD-MF-005`/`LLD-IR-010`). Cat C generation: `reward_score ≤
cost_score ÷ 1.7`; Option 2 cost strictly `< ` Option 1 cost (`LLD-MF-010`).

**Item data:** `AbilityData{ability_id, display_name, action_bucket ("attack"|"support"|"consumable"),
max_charges, score, handlers}`. Scale mapping: `attack`/`support` → **Durability** scale; `consumable`
→ **Consumable** scale. Items are `AbilityData` (`content.get_ability(id)`); `.score` is authored.

**Floor generation:** `FloorProfile` (Domain resource, `data/floors/*.tres`) currently has enemy/loot
pools, `temporary_companion_pool`, `pre_elite_rooms`/`post_elite_rooms`, `elite_gate_room()`,
`total_rooms()`. It has **no** MF/WS fields yet — PE0.2 adds them. `NavigationModel.generate_doors`
today emits combat/elite-gate doors only. Non-combat caps (`LLD-FLOOR-PATT-003`): MF pre 1–2 / post 1–2
(floor max 3); WS pre 0–1 / post **exactly 1** (floor 1–2). WS post-elite guarantee (`HLD-WS-008`):
if no WS occurred post-elite by the last pre-Judge slot, one door there is a WS. Floor-3 MF category
weights (`LLD-MF-007`): **40% Cat A / 40% Companion / 20% Cat C**. Companion pool (`LLD-MF-009`): the
three temp companions (already in `FloorProfile.temporary_companion_pool`).

**RunController hooks that already exist and will be reused:** `_enter_companion_beat(companion_id)`
(MF Companion reuses this verbatim), `_build_companion`, `_fire_replenish(ReplenishEvents.ENCOUNTER_START)`,
`_set_phase`, `_generate_doors`, `_complete_encounter` (support-item per-encounter decrement),
`_post_navigation` (dispatches on door `room_type`).

# @Spec: LLD-ARCH-021
#
# TradeGenerator — the sole builder of TradeOffer dictionaries for Wandering Soul
# and Memory Fragment Cat A / Cat C encounters (LLD-ARCH-021). Application layer,
# RefCounted, injected rng + content (mirrors LootGenerator). LOOT stream only for
# all item selection (LLD-ARCH-021 / LLD-ARCH-008). Does not mutate GameState —
# returns offer arrays RunController stores in NavigationState.event_offers.
class_name TradeGenerator
extends RefCounted

const STREAM_LOOT := 2  # RNGService.Stream.LOOT — never touch the autoload global directly

var _rng
var _content

func _init(rng = null, content = null) -> void:
	_rng = rng
	_content = content

# @Spec: LLD-IR-010
func is_fair_trade(score_a: int, score_b: int) -> bool:
	return absi(score_a - score_b) <= 0.20 * maxi(score_a, score_b)

# @Spec: LLD-IR-009
func hp_for_score(score: int, scale: String) -> int:
	match scale:
		"durability": return TradeTuning.durability_hp(score)
		"consumable": return TradeTuning.consumable_hp(score)
		_: return 0

# Scale of an item id: consumables → "consumable"; attack/support → "durability" (HLD-ITEMS-006).
func _scale_of(item_id: String) -> String:
	var d = _content.get_ability(item_id) if _content != null else null
	if d == null: return ""
	return "consumable" if d.action_bucket == "consumable" else "durability"

func _score_of(item_id: String) -> int:
	var d = _content.get_ability(item_id) if _content != null else null
	return d.score if d != null else 0

func _roll(a: int, b: int) -> int:
	if _rng == null or b <= a: return a
	return _rng.randi_range(STREAM_LOOT, a, b)
```

	# Try a same-scale, in-tolerance item-for-item pairing (player item ↔ pool item).
	for give_id in inv_ids:
		var scale := _scale_of(give_id)
		var gscore := _score_of(give_id)
		var candidates: Array = []
		for pool_id in pool:
			if _scale_of(pool_id) == scale and is_fair_trade(gscore, _score_of(pool_id)):
				candidates.append(pool_id)
		if not candidates.is_empty():
			var recv: String = candidates[_roll(0, candidates.size() - 1)]
			return _offer("item_for_item", give_id, 0, recv, 0)
	# Fallback (LLD-MF-008): item-for-HP on the highest-scored inventory item.
	if not inv_ids.is_empty():
		var best := _highest_scored(inv_ids)
		return _offer("item_for_hp", best, 0, "", hp_for_score(_score_of(best), _scale_of(best)))
	return {}  # no inventory at all → empty (RunController treats an empty offer as an auto-skip)

# --- shared helpers (used by WS / Cat C too) ---
func _offer(t: String, give_item: String, give_hp: int, recv_item: String, recv_hp: int) -> Dictionary:
	return {"offer_type": t, "give_item_id": give_item, "give_hp": give_hp,
		"receive_item_id": recv_item, "receive_hp": recv_hp}

func _inventory_ids(game_state: GameState) -> Array:
	var ids: Array = []
	for item in game_state.inventory:
		if item != null: ids.append(item.item_id)

func _durability_and_consumable_pool(game_state: GameState) -> Array:

	if p == null: return []

	out.append_array(p.normal_consumable_pool)

# @Spec: HLD-DOOR-001, LLD-FLOOR-PATT-003, HLD-WS-008
func generate_doors(game_state: GameState, profile: FloorProfile) -> Array:
	var next_room := game_state.navigation_state.rooms_completed_this_floor + 1
	if next_room > profile.total_rooms():
		return []
	if next_room == profile.elite_gate_room():
		return _elite_gate_doors(next_room, profile)

	var pre := next_room < profile.elite_gate_room()
	var seg := "pre" if pre else "post"
	var counts := game_state.navigation_state.segment_room_counts

	# HLD-WS-008: guarantee a WS at the final pre-boss slot if the post-elite WS cap wasn't met.
	var last_slot := next_room == profile.total_rooms()
	if profile.ws_post_elite_guaranteed and last_slot and int(counts.get("ws_post", 0)) < 1:
		return [
			_make_door(ROOM_WANDERING_SOUL, "", profile.floor_number, next_room, 0),
			_make_door(ROOM_COMBAT, _pick_one(profile.normal_enemy_pool), profile.floor_number, next_room, 1),
		]

	# Otherwise: door 0 may be a non-combat type if its segment cap is open; door 1 stays combat.
	var nc := _pick_noncombat_type(seg, counts, profile)
	if nc != "":
		return [
			_make_door(nc, "" if nc != ROOM_COMBAT else _pick_one(profile.normal_enemy_pool), profile.floor_number, next_room, 0),
			_make_door(ROOM_COMBAT, _pick_one(profile.normal_enemy_pool), profile.floor_number, next_room, 1),
		]
	return _combat_doors(next_room, profile)

# Choose a non-combat door type whose segment cap is still open, weighted by remaining headroom;
# returns "" to fall back to two combat doors. Uses the NAVIGATION stream.
func _pick_noncombat_type(seg: String, counts: Dictionary, profile: FloorProfile) -> String:
	var options: Array = []   # each entry: a room_type string, added once per unit of remaining headroom
	var mf_cap := profile.mf_cap_pre_elite if seg == "pre" else profile.mf_cap_post_elite
	var ws_cap := profile.ws_cap_pre_elite if seg == "pre" else profile.ws_cap_post_elite
	if int(counts.get("mf_%s" % seg, 0)) < mf_cap:
		options.append(ROOM_MEMORY_FRAGMENT)
	if int(counts.get("ws_%s" % seg, 0)) < ws_cap:
		options.append(ROOM_WANDERING_SOUL)
	# A coin-flip whether to offer a non-combat door at all, so combat stays common.
	if options.is_empty() or _roll(0, 1) == 0:
		return ""
	return options[_roll(0, options.size() - 1)]
```

```gdscript
# @Spec: UI-WS-002, UI-WS-003
class_name WanderingSoulViewModel
extends RefCounted

var _gs: GameState
var _legal: Array
var _content

func _init(gs: GameState, legal_actions: Array, content) -> void:
	_gs = gs; _legal = legal_actions; _content = content

func offer_rows() -> Array:
	var rows: Array = []
	var offers := _gs.navigation_state.event_offers
	for i in offers.size():
		var o: Dictionary = offers[i]
		rows.append({
			"give_label": _side_label(o.get("give_item_id", ""), o.get("give_hp", 0)),
			"receive_label": _side_label(o.get("receive_item_id", ""), o.get("receive_hp", 0)),
			"is_hp_for_item": o.get("offer_type", "") == "hp_for_item",
			"action": _accept_action(i),
		})
	return rows

func done_action() -> Dictionary:
	for a in _legal:
		if str(a.get("type", "")) == "DECLINE_TRADE":
			return a
	return {}

func _accept_action(i: int) -> Dictionary:
	for a in _legal:
		if str(a.get("type", "")) == "ACCEPT_TRADE" and int(a.get("offer_index", -1)) == i:
			return a
	return {}

func _side_label(item_id, hp) -> String:
	if str(item_id) != "":
		var d = _content.get_ability(item_id) if _content != null else null
		return d.display_name if d != null else str(item_id)
	return "%d HP" % int(hp)
```
