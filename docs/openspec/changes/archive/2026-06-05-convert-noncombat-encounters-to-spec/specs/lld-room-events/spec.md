## MODIFIED Requirements

### Requirement: [LLD-EVENTS-003] Rest / Mending Rooms
**Rest rooms are NOT present in the Floor 3 MVP room pool.** Rest has been removed from MVP. There is no guaranteed recovery room on Floor 3. Healing is available only through Wandering Soul item-for-HP trades (see `LLD-WS-004`) encountered through normal room generation, or the fixed post-elite HP restoration (see `LLD-EG-002`).

Future floors may include Rest rooms; this requirement will be updated when that design is confirmed.

#### Scenario: No rest room on Floor 3
- **WHEN** the Floor 3 room pool is generated
- **THEN** Rest / Mending is not present as a draw option; no rest room appears on Floor 3 through normal generation

## MODIFIED Requirements

### Requirement: [LLD-EVENTS-004] Anomaly Rooms
Anomaly rooms appear at Floor 3 exclusively as the alternative door at the Elite Gate (see `LLD-EG-001`). They are NOT in the general non-combat room pool for Floor 3 — the player encounters an Anomaly option only at the Elite Gate beat.

The Anomaly door's corrupted symbol (see `HLD-RUN-002`) signals risk without revealing outcome. Outcome is generated by `EncounterFactory.build_anomaly()`.

#### Scenario: Anomaly at Elite Gate only
- **WHEN** rooms are generated for Floor 3
- **THEN** Anomaly does not appear as a general pool draw; it appears only as one of the two Elite Gate door options

#### Scenario: Anomaly symbol still corrupted
- **WHEN** the Anomaly door is shown at the Elite Gate
- **THEN** the door displays the corrupted/unreadable Anomaly symbol (per `HLD-RUN-002`), not the elite combat symbol
